# olxpraca — Telegram-бот пошуку роботи на OLX

Бот шукає вакансії в розділі «Робота» на olx.ua і розкладає їх по категоріях
(завод, склад, касир, водій, будівництво, кафе, прибирання, охорона, офіс).

## Можливості
- 🔎 Пошук за категорією (кілька ключових слів на категорію, без дублікатів)
- ✍️ Пошук за власним запитом
- ⚙️ Фільтри: місто, мінімальна зарплата, слова-виключення
- ↕️ Сортування: спочатку нові / спочатку більша зарплата
- 🔔 Підписки: бот сам надсилає нові вакансії з обраних категорій
- Позначки категорій на кожному оголошенні, пагінація

## Запуск
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вставте токен від @BotFather
python -m olxbot.main
```

Категорії і ключові слова редагуються в `olxbot/categories.py`.

## Без сервера: розсилка через GitHub Actions
Файл `.github/workflows/notify.yml` кожні ~20 хв перевіряє OLX і надсилає нові
вакансії в Telegram. Налаштування (місто, категорії, з/п) — у блоці `env` цього файлу.
Потрібні секрети репозиторію: `BOT_TOKEN` і `CHAT_ID`.

Країна OLX задається змінною `OLX_COUNTRY` (`ua` або `pl`).
